# PowerTree v0.7.0 Audit — findings and disposition

Audit performed 2026-08-07 against v0.7.0, grounded with a 501-element probe
(solve 47 ms, layout 12 ms but 135,278 px wide, PNG render 8.4 s on the GUI
thread). Every finding below is tracked to a disposition; "v0.8.0" means
implemented and verified in that release.

## P0 — highest impact

| # | Finding | Disposition |
|---|---------|-------------|
| 1a | Wide-tree layout collapses into a 135k-px ribbon at real-board scale | **v0.8.0** — leaf-grid wrapping: >N leaf loads on one rail arrange as a grid inside a rail-group container with a single bus edge (threshold + on/off in Settings) |
| 1b | No orientation aid on large canvases | **v0.8.0** — click-to-navigate minimap overlay (toggleable) |
| 2a | Exports run on the GUI thread (8.4 s freeze measured) | **v0.8.0** — exports run in worker threads with a busy/progress dialog |
| 2b | Giant renders can exceed image limits | **v0.8.0** — renderer caps the longest image side (16k px) by auto-reducing scale |
| 3 | Jump-to-finding/search dead-ends on elements hidden in collapsed blocks/branches | **v0.8.0** — reveal-path: auto-expands collapsed ancestors and blocks before selecting |
| 4a | No drag-drop re-parenting | **v0.8.0** — list view drag-drop re-parent (model-validated) |
| 4b | No multi-delete | **v0.8.0** — canvas/list multi-select delete |
| 4c | No copy/paste of subtrees between trees/projects | **v0.8.0** — Ctrl+C/Ctrl+V subtree JSON via OS clipboard (works across app instances) |

## P1 — feature/model depth

| # | Finding | Disposition |
|---|---------|-------------|
| 5a | No resistive loads | **v0.8.0** — third load type (R, bounded), solved in the fixed-point loop |
| 5b | No duty-cycle semantics | **v0.8.0** — Load.duty_cycle_pct: typ corner uses the duty-weighted average, max corner keeps full peak |
| 5c | No unregulated (Vin-tracking) stages | **v0.8.0** — converter topology "unregulated": Vout = ratio × Vin per corner |
| 5d | No power-up sequencing checks | **v0.8.0** — Converter.seq_order + margin check: a rail enabled before its upstream rail is flagged |
| 5e | Parallel/ORed sources (diode-OR, load switches) | **ROADMAP** — requires multi-parent DAG (model, solver, layout, file format). Design sketch in ROADMAP.md; not faked with a half-model |
| 5f | Temperature derating curves for ratings | **ROADMAP** — needs per-part derating tables; the flat derating policy (v0.5.0) covers the common case meanwhile |
| 6 | Cross-tree nets are advisory, not electrically merged | **v0.8.0 (honesty) + ROADMAP (merge)** — Nets dialog/report now state the advisory scope explicitly; full cross-tree merged solving is a roadmap architecture item |
| 7 | Library lacks versioning/authorship, conflict handling, bulk export, per-project scope | **v0.8.0** — parts stamped with version/author/date (version auto-bumps on overwrite), import conflict prompt, Export-all, project-local library file loaded alongside the user library |
| 8 | Reports: no logo, no tree selection, waived findings not excludable | **v0.8.0** — project logo (embedded, shown on PDF/HTML title), pre-export dialog: pick trees + include/exclude waived findings |
